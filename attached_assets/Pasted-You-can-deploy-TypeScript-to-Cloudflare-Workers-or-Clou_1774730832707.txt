You can deploy TypeScript to Cloudflare Workers or Cloudflare Pages:

Workers
TypeScript is a first-class language for Workers with full API typing. Use the Workers dashboard to create a new Worker and select TypeScript as the language.

Pages
Use Pages Functions for serverless code in Pages projects. Put TypeScript files in the /functions directory (.ts extension).

Quick start with Wrangler:

bash


# Create a new Worker project with TypeScript
npm create cloudflare@latest my-worker
cd my-worker
# Generate types
wrangler types --path='./functions/types.d.ts'
# Deploy
npm run deploy
``

This is a pnpm lockfile configuration mismatch that's preventing your build from completing. The error message is clear about the solution.

Fix Options
Option 1: Update your lockfile (Recommended)
Run this locally in your project directory:

bash


pnpm install --no-frozen-lockfile
Then commit and push the updated pnpm-lock.yaml to your repository.

Option 2: Disable frozen lockfile in Cloudflare Pages
If you don't want to modify your lockfile, you can disable the frozen lockfile requirement:

Go to your Pages project settings
Find the Build settings section
Update the Install command to remove --frozen-lockfile:


pnpm install
(instead of pnpm install --frozen-lockfile)
